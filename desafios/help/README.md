# Help!

## Descrição

O programa calcula o placar de uma competição de programação. Para cada caso, informa quantos problemas foram resolvidos corretamente e o tempo total de penalidade.

Cada submissão incorreta de um problema que depois é resolvido corretamente acrescenta 20 minutos de penalidade. Erros em problemas que nunca foram resolvidos não contam para o tempo final.

## Arquivos

- `help.py`: solução em Python.
- `entrada.txt`: submissões dos casos de teste.
- `saida.txt`: quantidade de problemas resolvidos e tempo total.

## Como executar

```bash
python help.py
```

O programa lê `entrada.txt` e escreve o placar em `saida.txt`. O valor `0` encerra a entrada.
