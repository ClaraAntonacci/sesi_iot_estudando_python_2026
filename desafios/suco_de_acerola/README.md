# Suco de Acerola

## Descrição

Cada fruta produz 50 ml de suco. O programa calcula o volume, em litros, que cada amigo receberá quando o suco for dividido igualmente.

A conta é: quantidade de frutas × 50 ml ÷ 1000 ÷ quantidade de amigos. O resultado é apresentado com duas casas decimais.

## Arquivos

- `suco.py`: solução em Python.
- `entrada.txt`: quantidade de amigos e frutas em cada linha.
- `saida.txt`: volume de suco por amigo, em litros.

## Como executar

```bash
python suco.py
```

O programa lê `entrada.txt` e grava os resultados em `saida.txt`. A linha `0 0` encerra a entrada.
