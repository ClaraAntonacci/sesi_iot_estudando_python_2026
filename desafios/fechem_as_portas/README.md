# Fechem as portas!

## Descrição

Existem N portas inicialmente fechadas. Cada descendente troca o estado das portas cujos números são múltiplos do seu identificador. O programa informa quais portas ficam abertas ao final.

Uma porta fica aberta quando possui uma quantidade ímpar de divisores. Isso acontece somente com os números que são quadrados perfeitos (1, 4, 9, 16...).

## Arquivos

- `portas.py`: solução em Python.
- `entrada.txt`: casos de teste.
- `saida.txt`: resultado gerado pelo programa.

## Como executar

```bash
python portas.py
```

O programa lê `entrada.txt` e escreve o resultado em `saida.txt`. O valor `0` encerra a leitura dos casos.
