# Esquerda, Volver!

## Descrição

O recruta começa voltado para o norte. Para cada comando `D`, vira um quarto de volta à direita; para cada comando `E`, vira um quarto de volta à esquerda.

As direções são representadas por `N` (norte), `L` (leste), `S` (sul) e `O` (oeste).

## Arquivos

- `esquerda.py`: solução em Python.
- `entrada.txt`: casos de teste.
- `saida.txt`: resultado esperado.

## Como executar

```bash
python esquerda.py
```

O programa lê `entrada.txt` e escreve as direções finais em `saida.txt`. O valor `0` encerra a entrada.
