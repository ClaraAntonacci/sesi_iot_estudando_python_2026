# Estudando Python

Lista de exercícios de Python resolvida em aula do SESI SENAI no curso Técnico em Desenvolvimento de Sistemas.

## Tecnologias

- Python
- VS Code

## Desafios

Os quatro desafios estão na pasta `desafios`. Cada desafio possui um arquivo Python, `entrada.txt`, `saida.txt` e um `README.md` com a descrição e as instruções.

## Para testar

Abra o terminal na pasta do desafio e execute:

```bash
python nome_arquivo.py
```

Por exemplo, para executar o desafio Fechem as portas:

```bash
cd desafios/fechem_as_portas
python portas.py
```

O programa lê os dados de `entrada.txt` e grava os resultados em `saida.txt`.
